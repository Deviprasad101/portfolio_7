PROJECT 02 Enterprise GIS · PostGIS · 3D Cesium

GEO INTEL META HUB

Problem

Scattered geospatial data (vectors, rasters, LAS point clouds, and 3D models) is hard to store, publish, and view in one centralized place.

Solution

Automated pipeline where a Flask application ingests uploaded spatial files → processes into PostGIS + GeoServer → serves a unified web UI for search, 2D maps, and 3D globes.

Outcome

Central metadata catalog with OGC WMS/WFS (plus rasters and 3D tiles) enabling users to discover, preview, and serve geospatial layers from a single platform.

Python / Flask PostgreSQL / PostGIS GeoServer GDAL / PDAL / ogr2ogr HTML / JS Cesium 3D
